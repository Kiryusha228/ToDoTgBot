# Пет-проект: Telegram-бот для управления задачами Todo-List

Первый полноценный проект, написаный на Java, с использованием Spring Boot.  
Целью проекта было изучение работы с Java и сопутствующем с языком стеком, также изучение работы мини-приложений в Telegram.

## В рамках проекта:
- Разработал структуру небольшой базы данных и настроил её взаимодействие с приложением.
- Реализовал REST API на Java с использованием Spring Boot и Hibernate.
- Настроил взаимодействие с Telegram API для обработки команд и визуализации пользовательского интерфейса.
- Развернул приложение на VPS-сервере в Docker-контейнере.
- Разработал простой веб-интерфейс на React для добавления и редактирования задач, который использовался как мини-приложение.

## Стек технологий:
Java 17, Spring Boot, Hibernate, PostgreSQL, Docker, Docker-compose, React.
